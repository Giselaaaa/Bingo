BINGO - VOZ ANIMADA CON RIMAS CLÁSICAS

La voz anuncia los números en español y añade rimas solo a números clásicos (1, 2, 5, 7, 8, 10, 11, 15, 22, 33, 44, 55, 66, 77, 88 y 90).
Se utiliza la mejor voz española disponible en el dispositivo, con ritmo algo más animado. La naturalidad depende de las voces instaladas.

Abre index.html con Live Server. Para actualizar GitHub Pages, sube el contenido de esta carpeta al repositorio.
Si el iPhone sigue usando una versión anterior, cierra la app y vuelve a abrirla después de publicar los cambios; en algunos casos puede ser necesario reinstalarla.

Cantos tradicionales personalizados: 1, 4, 6, 7, 8, 9, 11, 13, 15, 22, 24, 25, 40, 55, 60, 69, 77, 89. Los demás números se anuncian normalmente.
